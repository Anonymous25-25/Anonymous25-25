
# 💫 About Me:
I’m Youness Boussedari, a Cybersecurity student and aspiring Security Engineer with a strong interest in offensive security, infrastructure security, cloud security, and enterprise environments.<br><br>My cybersecurity journey started with networking and system administration, then progressively moved toward penetration testing and security engineering. I’m particularly interested in understanding how real-world infrastructures are built, attacked, defended, and secured — from networks and Active Directory environments to web applications, cloud services, and security monitoring platforms.<br><br>I have hands-on experience working with Linux and Windows environments, Active Directory, DNS, networking, virtualization, Docker, web technologies, and security tools such as Nmap, Wireshark, Burp Suite, Metasploit, Nessus/OpenVAS, Gobuster, SQLmap, John the Ripper, Aircrack-ng, Nikto, and OWASP ZAP.<br><br>My practical work focuses on building realistic cybersecurity labs and simulating enterprise environments rather than relying only on theoretical knowledge. I have worked on vulnerable environments involving Active Directory, Windows Server, web applications, internal networks, firewalls, databases, and segmented infrastructures. I’m also developing larger projects such as RedSiege, a full-scope Red Team simulation designed around realistic attack chains from external reconnaissance and initial access to internal compromise and protection of critical assets.<br><br>I’m also interested in the intersection between Cybersecurity and Artificial Intelligence. I have explored projects involving AI-assisted penetration testing, vulnerability detection, SOC automation, and AI-powered security workflows. One of my main ideas is PenCopilot, an AI-powered penetration testing workspace designed to act as an intelligent teammate during security assessments — helping analyze reconnaissance results, identify potential attack paths, and recommend the next steps.<br><br>Beyond offensive security, I’m expanding my knowledge toward Security Engineering, with a focus on enterprise infrastructure, Active Directory, cloud platforms, security monitoring, automation, and defensive architecture. I’m interested in understanding both sides of cybersecurity: how attackers think and operate, and how organizations can design systems that are resilient against those attacks.<br><br>My current technical interests include:<br><br>• Penetration Testing & Red Teaming<br>• Web Application Security<br>• Active Directory & Windows Security<br>• Network Security & Infrastructure<br>• Linux & Windows Administration<br>• Cloud Security<br>• SOC & Security Monitoring<br>• Vulnerability Assessment<br>• Python & Bash Automation<br>• Docker & Virtualization<br>• AI-assisted Cybersecurity<br>• Security Engineering<br><br>I believe the best way to learn cybersecurity is through continuous hands-on practice: building environments, breaking them, investigating what happened, fixing the weaknesses, and documenting the entire process.<br><br>My long-term goal is to become a highly capable Security Engineer with strong offensive-security foundations, capable of designing, securing, testing, and improving modern enterprise infrastructures.<br><br>I’m continuously building, learning, documenting, and turning each project into practical experience.<br>
